# tools

## extract_upb_plan.py

Reads the official UPB study plan from the faculty's AQ portal and writes
one teacher agent per course, with the Romanian name, ECTS, weekly hours and
lecturer for every discipline.

## extract_epic_curriculum.py

Extracts the Erasmus partner tracks from the E-PiCo+ programme handbook.

## make_teacher.py

Writes a single teacher agent from a course code, title and material folder.

## make_agent.py

Writes a custom agent from a name, role, description, capabilities, skill
folders and RAG sources. Use this for any agent that is not a teacher.
